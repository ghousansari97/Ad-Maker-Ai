# AdMaker AI — MVP v0.1

Flutter MVP for an AI Video Ad Maker for local businesses.

## Current MVP
- Home screen
- Create New Advertisement form
- Business information fields
- Category, language, duration, style and voice selectors
- Preview screen
- Placeholder Download/Share actions

## Planned next phases
1. Firebase authentication
2. Logo/product image upload
3. Secure backend
4. AI script generation
5. AI voice generation
6. Visual/video generation
7. Captions and MP4 rendering
8. Real download/share
9. Credits/payments
10. Testing and Play Store release

## Target video
9:16 vertical, 1080x1920 for WhatsApp Status, Facebook/Instagram Reels, TikTok and YouTube Shorts.

## Important
AI/API keys must not be placed inside the Flutter mobile app. Use a secure backend.
